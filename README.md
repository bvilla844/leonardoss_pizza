📌 Leonardoss Pizza - Base de Datos

🍕 Descripción del Proyecto

Leonardoss Pizza es un sistema de base de datos diseñado para gestionar eficientemente las operaciones de una pizzería. Incluye la administración de órdenes, clientes, productos, inventario, empleados y la gestión de turnos y salarios. Además, se han desarrollado dashboards en Grafana para la visualización de datos clave del negocio.

📂 Estructura de la Base de Datos

La base de datos leonardoss_pizza contiene las siguientes tablas principales:

ordenes: Registro de pedidos realizados por los clientes.

cliente: Información de los clientes.

direccion: Datos de dirección de los clientes.

producto: Catálogo de productos disponibles en la pizzería.

receta: Relación entre productos e ingredientes.

ingrediente: Detalle de los ingredientes utilizados.

inventario: Control de stock de ingredientes.

empleados: Información del personal de la pizzería.

turno: Horarios de trabajo del personal.

rotacion: Registro de turnos de los empleados.

📊 Dashboards en Grafana

Se han implementado dashboards en Grafana para la visualización de métricas clave, incluyendo:

Órdenes totales y cantidad de pizzas vendidas.

Ganancias totales y ganancias por producto.

Gastos en ingredientes y control de inventario.

Salarios de empleados y costos de nómina.

⚙️ Consultas SQL Implementadas

Se han desarrollado diversas consultas SQL para analizar y extraer información clave, como:

Total de órdenes realizadas.

Ganancias totales de la pizzería.

Cantidad total de pizzas vendidas.

Ventas por tipo de pizza.

Costos de ingredientes y control de inventario.

Salarios de empleados y costo total de nómina.
